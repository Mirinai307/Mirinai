## v1.1 — 2026-07-27

v1.0 검토 결과 발견된 결함 11건을 보완했다.

### 전면 개정

- **§10 실행 환경** — Windows PC 단독 실행에서 **GitHub Actions cron 주 / Windows self-hosted 폴백**으로 전환.
  PC 전원 상태와 무관하게 매일 실행되도록 하여 수집 누락의 구조적 위험을 제거. cron UTC 변환값과
  무료 한도 계산(약 300분/월) 명시. 해외 IP 차단 소스는 국내 러너로 라우팅.
- **§8 토큰 비용 모델** — "토큰 0"의 경계를 **3-Tier 모델**로 명확화.
  Tier 0(상시, 0원) / Tier 1(규칙이 판단 실패한 신규 공고만, 일 3건·월 예산 상한, 초과 시 자동 강등) /
  Tier 2(사용자 지목 시). `ai_review.enabled: false` 로 완전 토큰 0 운영도 가능.

### 신설

- **§5.2 복제 공고 클러스터링 알고리즘** — v1.0의 "유사도로 묶되"를 구현 가능한 규칙으로 구체화.
  정규화 제목 토큰 자카드 ≥ 0.85 **AND** 접수기간 겹침 **AND** 지역 일치. 0.70~0.85 구간은 자동 병합 금지.
- **§6.2 추출 신뢰도 등급 A/B/C** — HWP(OLE)의 표 텍스트 유실이 조용한 미탐으로 이어지는 문제 대응.
  **신뢰도 C 문서는 '제외' 판정 금지, '검토대기' 강제.** 동일 공고의 여러 첨부 중 최고 등급 추출문을 사용.
- **§7.2 미탐 방지 원칙** — 지역·지원유형 파싱 실패, 사전에 없는 신규 용어 포함 공고도 제외 금지.
- **§7.3 규칙 피드백 루프** — `feedback.yaml` 누적 → 주간 규칙 갱신 → 최근 30일 재판정으로 신·구 규칙 비교.
- **§9.3 필요서류 대조** — 필요서류 사전 추출 + 보유서류 대장(`documents_owned`) 대조로 부족서류 표기(O/△/X).
  발급 소요일이 긴 미보유 서류는 마감 역산 경보.
- **§11.2 데드맨 스위치** — 24시간 무성공 시 조건 없이 경보. 소스별 마지막 성공 시각을 보고서 최상단 상시 노출.
  3회 연속 실패 소스 자동 중단. '정상 0건'과 '장애' 구분.
- **§12 신청 작업대장과 중복수혜 관리** — 발견→검토→서류준비→제출→결과대기→선정/미선정→정산 상태머신.
  자동 입력은 '발견'까지만. 기수혜 이력과 충돌 시 자동 제외가 아닌 "중복수혜 확인 필요" 경고.
- **§15 버전 관리 정책** — 원본(Git)·배포본(Drive)·이력(CHANGELOG) 3계층. 덮어쓰기 금지.

### 변경

- **§4 수집 대상** — 공공데이터포털 오픈API를 **A등급으로 승격**.
  K-Startup 공고 API(v1.0에서는 C등급 HTML), 소상공인시장진흥공단 API, 보조금24 맞춤서비스 목록 추가.
  우선순위를 `RSS → API → HTML` 에서 `오픈API → RSS → HTML` 로 조정. 조달(나라장터)은 범위 제외 명시.
- **§13 보안** — 시크릿 관리를 **GitHub Secrets 우선**으로 변경(self-hosted 실행 시에만 Windows 자격증명 저장소).
  커밋 전 시크릿 스캔 추가.
- **§14 시험** — 추출 신뢰도 등급, 신뢰도 C 미탐 방지, 클러스터링 임계값, Tier 1 상한, Watchdog 시험 추가.
  **개발 환경에서 정부 사이트 접근이 차단될 수 있으므로 고정 픽스처 기반 오프라인 시험을 기본**으로 명시.
- **부록 B** — v1.0의 접속 검증 결과를 "v1.0 작성 시점 사용자 환경 기준 확인값, 구축 0단계에서 재검증" 으로
  단서 표기. GitHub Actions 해외 IP 차단 가능성을 유의사항에 추가.
