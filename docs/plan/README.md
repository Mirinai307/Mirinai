# 소상공인 정부지원·정책금융 공고 자동수집

원카샵·수원별당 두 사업장을 대상으로, 중앙정부·경기도·수원시·보증기관에 흩어진
지원금·보조금·정책자금 공고를 **매일 자동 수집**하고 사업장 조건에 맞춰 선별하는 시스템의
기획·설계 문서입니다.

핵심 원칙은 **토큰 0 기본**입니다. 매일 반복되는 수집·중복검사·첨부보관·마감추출·1차 분류는
LLM 없이 규칙으로 처리하고, 규칙이 판단하지 못한 소수 공고만 상한이 걸린 AI 검토로 넘깁니다.

## 배포본(.docx) 생성

기획안 Markdown을 Word 문서로 변환합니다. 버전업 시 다시 실행해 배포본을 만듭니다.

```bash
npm install docx
node tools/md2docx.js \
  "docs/plan/소상공인_정부지원_정책금융_공고_토큰0_자동수집_상세기획안_v1.1.md" \
  "소상공인_정부지원_정책금융_공고_토큰0_자동수집_상세기획안_v1.1_2026-07-27.docx"
```

`tools/md2docx.js` 는 ATX 헤딩, 문단, GFM 표, 코드펜스, 인용구, 목록, 수평선과
인라인 `**굵게**` · `` `코드` `` 를 처리합니다. 표는 열별 최대 글자수에 비례해 폭을 배분하고,
문단 테두리는 한 면만 사용합니다(docx-js가 테두리를 `top,bottom,left,right` 순으로 쓰는데
OOXML 스키마는 `top,left,bottom,right`를 요구하므로 여러 면을 섞으면 검증에 실패합니다).
